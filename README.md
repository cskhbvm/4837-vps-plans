## 4837 大带宽是什么，为什么这条线敢给 1Gbps

AS4837 是中国联通的国际骨干网络，业内常说的 CUVIP 就是它。卖 4837 的商家做法基本一致：三网回程强制走 4837，去程各自直连。电信走骨干直连出去，联通走 AS4837 直连，移动走移动骨干直连过去，回来的时候三家统一从联通 4837 出来。六六云这台机器上的回程测试结果也是这样，北京、上海、广州、成都四地的电信、联通、移动回程，逐条查下来都是 AS4837，没有绕路。

带宽能开这么大，原因在线路成本。4837 的带宽成本比联通 9929 低不少，商家才敢把端口开到 300Mbps、500Mbps 甚至 1Gbps。9929 是联通更高一档的精品线，延迟和稳定性更好，但端口通常从 50Mbps 起步，价格门槛也更高。同价位横向比，4837 给的带宽常常是 9929 的几倍，这就是“大带宽”三个字的由来。

有个地方必须说清楚：大带宽指的是端口峰值，不是独享。这类 4837 大端口机器跑的是共享线路，商家普遍只承诺 99% 的时间段能达到标称带宽，并在服务条款里禁止长期占满。你打算 7×24 小时把 1Gbps 拉满做下载站或者视频分发，4837 大带宽不适合，任何一家标 1Gbps 的共享方案都不适合。

## 4837大带宽的四个短板，以及哪些人别买

第一是移动用户。三网回程全部走 AS4837，对联通用户最友好，电信次之，移动最吃亏。移动去程走自己的骨干直连，回程却要绕到联通的 4837 上出来，延迟普遍比电信、联通高出一截。这是 4837 这条线路对移动用户的通病，不是六六云一家的问题。第三方测评那台年付机用的是电信线路，延迟 186ms，属于正常的中美延迟水平。移动宽带是主力、又在意响应速度的，先去翻翻同家的 9929 或 CN2 GIA 产品线。

第二是延迟敏感型业务。游戏加速、实时语音、要求延迟必须压在 180ms 以内的 API 调用，4837 给不了这个确定性。要低延迟就得多花钱上 9929 或者 CN2 GIA，这是线路定位决定的，跟商家优不优化没关系。

第三是标称端口和实际速度的落差。同一份第三方测评里，那台 1Gbps 端口的机器电信单次测速是下载 8.43Mbps、上传 63.10Mbps。单次测速受测速节点、时段、本地带宽影响，不能当成线路上限，但它至少说明 1Gbps 是端口规格，你实际能跑出多少还得看当时的路况和对端。

第四是 IP 属性的边界。六六云这台机器在多个数据库里被识别为美国原生 IP、家宽类型，风险评分低、黑名单记录为 0，流媒体和 AI 平台基本都能识别成美区。但同一份检测里，IP2Location 把它判定成了 IDC 机房 IP。数据库之间的判定标准不一样，你要拿它过某个具体平台的风控，别只看“原生住宅”四个字，先用最小配置试一个月更稳妥。

## 常见问题

### 4837 和 9929 哪个好？

看你要什么。要带宽和便宜，选 4837，同价位给的端口是 9929 的好几倍。要低延迟和稳定性，选 9929，但端口小、价格高。做 TikTok 运营、流媒体解锁、外贸建站这类对延迟不敏感的活，4837 更划算；跑游戏、实时通信，多花钱上 9929 或 CN2 GIA。

### 移动宽带能用吗？

能用，但延迟会比电信、联通高。原因是回程统一走联通 AS4837，移动用户要绕一段。日常刷网页、看视频、跑运营脚本不受影响，对响应速度有要求的操作会感觉到差别。

### 1Gbps 是独享的吗？

不是。这是共享线路上的端口峰值，商家一般只承诺 99% 时间段达标，并禁止长期占满带宽。当成“高峰期大概率能跑到很高的速度”来理解比较准确，当成“随时 1Gbps 独享”会失望。

### 这个 IP 到底算不算原生住宅 IP？

多数 IP 数据库把它识别为美国原生、家宽类型，风控评分和黑名单记录都干净，流媒体和 AI 平台基本识别为美区。但 IP2Location 这类库会判成 IDC 机房 IP。数据库口径不统一是常态，你要过哪个平台的风控，就拿那家平台实测，别只看检测报告。
